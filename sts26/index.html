Como montar no vMix

  1. Add Input → Web Browser, cole a URL, tamanho 1920×1080. O fundo das peças é transparente.
  2. O Overlay (todas as peças) fica num canal de Overlay ligado o tempo todo; quem decide o que aparece é o controle remoto. Se preferir uma peça por input, use os overlays separados.
  3. Nas telas Intervalo e Dividida, as janelas das câmeras são vazadas: monte as câmeras nas camadas de baixo (posições na tabela de cada tela) e a tela por cima.
  4. O dia do evento (DIA 1/2/3) troca em todas as telas pelo controle. Para fixar um dia, use os PNGs abaixo.
  5. Teste antes na sala de ensaio: é idêntica, mas separada da live.
